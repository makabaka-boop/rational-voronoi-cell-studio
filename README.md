# 站点服务区编辑器（精确 Voronoi Cells）

不联网的站点编辑器：对矩形区域内的站点，用**平方欧氏距离**逐个切出凸多边形服务区
（Voronoi 单元），输出精确顶点、精确面积与正长度邻接边；React + TypeScript + SVG
绘制，Docker Compose 中 `cells` 服务（nginx）托管页面。

```
docker compose up --build
# 打开 http://localhost:8080
```

## 功能

- 输入整数宽高（100～1000）与 2～30 个唯一 ASCII id 站点；坐标为区域内整数，
  **重合坐标拒绝**（UI 拖动时同样拒绝落到已有站点上）。
- 每个站点依次以「到自己的平方距离 ≤ 到其它站点的平方距离」半平面裁切矩形，
  得到凸单元；列表与 SVG 图形读取**同一份计算结果**（`computeCells` 的 `useMemo`）。
- 输出每个单元的：
  - 顶点（最简分数 `n/d`）
  - 精确面积（鞋带公式，bigint 有理数）
  - 共享**正长度边段**的邻接站点 id（边两端点都在同一条等分线上才算）
  - 每条边标注 `等分线 ↔ 邻居` 或 `矩形边界`
- 边界查询：点击画布给出命中站点与全部站点的精确平方距离证据；等距时按
  **站点 id 字节序**（UTF-8 字节，ASCII 即代码点序）取胜。
- 归属不随 SVG 缩放改变：浏览器事件坐标经 `getScreenCTM().inverse()` 还原到
  viewBox 逻辑坐标后，把 IEEE-754 double **按位精确**转成有理数（`fractionFromNumber`），
  再进入同一套精确比较管线——从不用画布像素猜边界。

## 精确性设计

- 所有坐标/系数是 bigint 最简分数（分母恒正）；裁切用 Sutherland–Hodgman，
  交点由直线方程精确求出。
- 半平面：站点 `s` 相对 `t` 的 `|p-s|² ≤ |p-t|²` 等价于
  `2(s−t)·p + |t|² − |s|² ≥ 0`。
- 无任何浮点参与归属判定；double→分数直接解码 64 位位模式（规格化/非规格化）。
- 裁切后剔除相邻重复点与共线中间点（精确叉积），避免零长边与假邻接。

## 本地开发

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest：小区域整数点穷举
npm run build    # tsc 类型检查 + 生产构建到 dist/
```

## 测试覆盖（Vitest）

- **双站点平分**：100×100 全部 101×101 个整数点核对最近站点、等距与距离证据。
- **共线点**：三站点共线，中间单元/两侧面积与邻接（非相邻站点不形成边）。
- **角落裁切单元**：5×5 上分数顶点（如 `5/2, 5/2`）、面积 `25/4`、`75/8`，
  三单元面积精确求和为 25，邻接边双向端点一致。
- 24 组确定性随机小区域（4～8）：穷举所有整数查询点对比朴素枚举，
  校验面积划分完整、邻接对称、胜者满足全部半平面。
- id 字节序决胜（含分数查询点）、缩放换算不变性、double 精确转换、输入校验。
